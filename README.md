# DEVFOLIO — запуск как обычного сайта

## Быстрый тест (без настройки)
Откройте `index.html` двойным кликом. Регистрация и вход работают сразу в **локальном режиме**:
данные хранятся только в вашем браузере (удобно проверить сайт, но другие люди их не увидят).
Когда будете готовы к настоящему сайту, выполните шаги ниже: после заполнения `config.js` сайт сам переключится на Supabase.

## Настоящий сайт (Supabase + хостинг)

1. **Supabase.** Зайдите на supabase.com, создайте проект (New project).
2. **База.** Откройте SQL Editor, вставьте содержимое `schema.sql`, нажмите Run.
3. **Почта.** Authentication -> Providers -> Email: для первого теста выключите «Confirm email».
4. **Ключи.** Project Settings -> API: скопируйте Project URL и ключ `anon public` в файл `config.js`.
5. **Публикация.** Откройте app.netlify.com/drop и перетащите всю папку с этими файлами. Вы получите ссылку `https://....netlify.app`.
6. **Supabase -> Authentication -> URL Configuration:** впишите эту ссылку в Site URL.
7. **Бот.** В `devfolio_bot.py` укажите эту ссылку в `APP_URL` и запустите бота.

## Проекты
В форме проекта можно загрузить обложку (картинка) и **файлы сайта**: выберите сразу несколько файлов (html, css, js, картинки, шрифты, видео), либо папку проекта целиком, либо один `.zip`. Всё склеивается в одну страницу и показывается на странице проекта как живое демо (до 3 МБ).
Не поддерживается: переходы между несколькими html-страницами, `fetch()` к своим файлам и ES-модули (`import`).
